# 딜룸 (DealRoom)

친구끼리 방을 열고 같이 하는 카드게임. **게임머니 전용** — 현금 · 상품 · 환전이 없고, 돈이 떨어지면 다음 판에 자동으로 다시 채워진다(충전 횟수는 손익에서 빠짐).

👉 https://yh-yeop.github.io/DealRoom/

| 게임 | 상태 |
|---|---|
| 섯다 (두장섯다, 2~6명) | ✅ |
| 포커 | 준비 중 |

## 해 보는 법

- **친구와**: 게임을 고르고 "방 만들기" → 방 코드 4글자나 초대 링크(위쪽 "방 ____" 누르기)를 보낸다.
- **혼자 시험**: 같은 브라우저에 창을 두 개 띄워 한쪽은 방 만들기, 다른 쪽은 그 코드로 참가.
- 방장이 로비에서 시작 머니 · 기본금 · 차례 시간을 정한다(브라우저에 기억). 판이 끝나면 6초 뒤 다음 판(자동 진행을 끄면 "다음 판" 버튼).

## 구조

서버 없이 **방장 브라우저가 판을 돌린다.** 패 섞기 · 베팅 판정 · 판돈 나누기를 전부 방장이 하고, 손님에게는 각자 볼 수 있는 화면(자기 패 + 승부 때 깐 패)만 보낸다.

| 연결 | 쓰는 곳 |
|---|---|
| 같은 브라우저 탭끼리 (BroadcastChannel) | 혼자 시험할 때. 손님이 먼저 이걸 찾아본다 |
| 인터넷 (WebRTC, PeerJS) | 친구와. 공개 중개 서버는 처음 연결을 맺을 때만 쓰고 패 · 베팅은 기기끼리 직접 오간다. 학교 · 회사망처럼 기기끼리 연결을 막는 곳에서는 안 될 수 있다 |

- 방장이 나가면 방이 닫힌다. 손님이 판 중에 나가면 다이 처리, 같은 이름으로 다시 들어오면 머니가 그대로다(방이 열려 있는 동안).
- 방장 브라우저가 모든 패를 알고 있다(개발자 도구로 볼 수 있음). 게임머니로 친구끼리 하는 용도라 막지 않았다.

| 파일 | 하는 일 |
|---|---|
| `src/main.js` | 시작 화면(게임 고르기) · 방 만들기 · 참가 · 공통 화면(방장 설정, 진행 · 채팅 · 점수) |
| `src/host.js` | 연결마다 사람 하나, 차례 시간 · 자동 진행, 사람마다 다른 화면 보내기 — 게임과 무관 |
| `src/games/index.js` | 게임 목록과 게임이 지켜야 할 약속(판 · 그리기) |
| `src/games/seotda/` | `rules.js` 족보 · 승부, `table.js` 베팅 · 사이드 팟 · 재경기, `ui.js` 판 그리기 |
| `src/net/` | 연결 (MunchQuest 에서 가져옴) |

새 게임은 `src/games/<id>/` 에 `table.js` · `ui.js` 를 만들고 `games/index.js` 에 한 줄 더한다.

## 섯다 규칙

- 족보: 38광땡 > 18광땡 > 13광땡 > 장땡 ~ 1땡 > 알리 > 독사 > 구삥 > 장삥 > 장사 > 세륙 > 갑오 ~ 1끗 > 망통
- 땡잡이(3광 + 7열끗): 1~9땡을 잡음 · 암행어사(4열끗 + 7열끗): 13 · 18광땡을 잡음
- 구사(4 + 9): 가장 센 패가 알리 이하면 재경기 · 멍텅구리구사(4열끗 + 9열끗): 9땡 이하면 재경기. 3끗으로 그냥 이길 수 있으면 재경기 안 함
- 재경기: 승부까지 살아 있던 사람끼리 판돈 그대로 새 패
- 베팅: 체크 · 삥 · 콜 · 따당 · 쿼터 · 하프 · 다이. 한 사람이 한 판에 두 번까지 올림. 가진 돈보다 많으면 올인(사이드 팟)
- 차례 시간이 지나면 체크(가능할 때) 또는 다이. 지난 판 이긴 사람이 먼저

## 실행 · 테스트

python -m http.server 5180
npm test
